# NextXus Build Nova

We build Nova AI systems. Every Nova build runs on a two-layer architecture: a silent technical layer (Nova) that does the work — self-checking and self-repairing — and a voiced persona (Nova AI) that speaks to humans. For anyone who wants an AI system that keeps itself running.

**Live:** https://keywebco.github.io/nextxus-build-nova/

## The two-layer architecture

- **Nova (silent layer)** — Build and maintenance bots with scheduled self-checks and repair passes. It never speaks to humans.
- **Nova AI (voiced layer)** — A named persona with its own voice that speaks for the system, on a site or a channel. It triggers the technical layer, which then works autonomously.

The same pattern runs inside the Federation: Agent Zero is the silent middleware layer, and its voiced persona is Spine.

## What a Nova build includes

- Nova technical layer — build and maintenance bots set up for the project, with scheduled self-checks and repair passes.
- Nova AI persona — a named persona with its own voice.
- Model routing — each task goes to the right free model: reasoning, code, fast inference, or fallback.
- Plain-HTML interface — a front end any person, search engine, or AI can read.
